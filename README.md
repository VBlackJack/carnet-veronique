# Le carnet de Véronique

*[Version française](README.fr.md)*

A shelf of hand-drawn detective games, in French, played in the browser. Each investigation stars
Véronique, an optician with a sharp eye, with her family and a kid goat called Biscotte.

## Play

Open the site's home page and pick an investigation. Everything runs in the browser; progress is
saved automatically. Phones work in landscape, with a fullscreen button.

## Structure

| Path | Content |
|---|---|
| `index.html` | The shelf |
| `engine/` | The shared game engine, drawing kit and interface texts |
| `episodes/<name>/` | One investigation: its story, scenes, characters and texts |
