# Le carnet de Véronique

*[English version](README.md)*

Une étagère de jeux d'enquête dessinés à la main, en français, dans le navigateur. Chaque enquête
met en scène Véronique, opticienne à l'oeil sûr, avec sa famille et un chevreau nommé Biscotte.

## Jouer

Ouvrir la page d'accueil du site et choisir une enquête. Tout se passe dans le navigateur, et la
partie est sauvegardée automatiquement. Sur téléphone, le jeu se joue à l'horizontale, avec un
bouton plein écran.

## Organisation

| Chemin | Contenu |
|---|---|
| `index.html` | L'étagère |
| `engine/` | Le moteur commun, le kit de dessin et les textes de l'interface |
| `episodes/<nom>/` | Une enquête : son histoire, ses décors, ses personnages et ses textes |
